# 鹈鹕骑行 · Pelican Ride 🐦🚲

一只鹈鹕，一辆自行车，一条无尽的海岸公路 —— 纯静态单文件 3D 网页游戏。

## 怎么玩

- **直接双击 `index.html`** 即可开始（首次打开需要联网，用于从 CDN 加载 three.js 引擎；之后同一浏览器有缓存）。
- 也可以用任意静态服务器运行，例如：`python -m http.server 8123`，然后访问 `http://localhost:8123`。

## 操作

| 按键 | 功能 |
| --- | --- |
| ← → 或 A D | 左右移动 |
| 空格 / W / ↑ | 跳跃（空中再按一次 = 展翅滑翔） |
| S / ↓ | 刹车 |
| H | 车铃（会把附近的海鸥吓飞） |
| P / Esc | 暂停 |
| M | 静音 |
| R | 重新开始（结算/暂停时） |

手机浏览器会自动出现触屏按钮。

## 玩法要点

- 🐟 吃鱼得分，连续吃鱼有 ×2 ~ ×5 连击加成；金鱼更值钱
- ⭐ 海星 +60 分；🛡️ 护盾挡一次撞击；🧲 磁铁吸鱼；❤️ 回血
- ⚡ 黄色箭头是加速带
- 🦀 螃蟹会横着走、🏖️ 沙滩球会滚、木箱堆只能绕、海鸥会俯冲 —— 跳或躲！
- 💨 水洼会减速；撞到障碍掉一颗心，共三颗心
- 🌅 从黄昏骑到深夜再到黎明，昼夜循环 4 分钟一轮：夜里车灯、路灯、灯塔、萤火虫都会亮起来

## 技术说明

- 单个 `index.html`（约 2000 行）：无构建、无框架、无素材文件，所有模型（鹈鹕、自行车、棕榈、海豚…）均为程序化建模，音乐与音效由 WebAudio 实时生成。
- 渲染：three.js + UnrealBloom 泛光 + ACES 色调映射 + 自定义海洋/天空着色器。
- three.js 从 jsDelivr / unpkg / npmmirror 三个 CDN 依次尝试加载，全部失败时显示友好提示。
- 本地持久化：最高分、最远距离、累计吃鱼数、音量与画质设置（localStorage）。

## 调试参数（URL 查询串）

- `?cycle=40` —— 昼夜循环缩短为 40 秒
- `?t=0.33` —— 直接从深夜开始
- `?q=fast` —— 强制流畅画质（自动判定：触屏设备默认流畅）
