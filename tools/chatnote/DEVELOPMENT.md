# ChatNote 对话式笔记工具 · 开发文档

> 纯静态单页工具，移动端优先。以「话题 → 对话流」的形式记笔记，交互上贴近常见 IM（微信传输助手式），数据全部保存在浏览器本地，无服务器、无账号。
>
> 产出物：本目录下单个 `index.html`（原生 HTML/CSS/JS，无构建、无外部依赖）。

---

## 1. 需求澄清与补充

原始需求之外，为补齐闭环，以下条目为建议新增（可在评审时裁剪）：

| # | 条目 | 说明 | 性质 |
|---|------|------|------|
| 1 | 消息可删除 | 原需求只有编辑/复制，笔记工具必须能删 | 必要补充 |
| 2 | 话题可重命名/删除 | 有新建就要有管理；删除需二次确认 | 必要补充 |
| 3 | 「已编辑」标记 | 编辑保留原始发送时间，显示已编辑徽标 | 体验补充 |
| 4 | 多选模式下「删除所选」 | 与多选导出共用一套选择逻辑，清理旧笔记很实用 | 建议补充 |
| 5 | 列表预览显示草稿 | 「草稿：xxx」前缀，让"未发送内容已保存"可感知 | 建议补充 |
| 6 | 剪贴板/下载降级方案 | 页面可能以 file:// 打开（非 https），Clipboard API 不可用，需 execCommand 降级 | 技术必要 |
| 7 | 深浅色跟随系统 | CSS 变量实现，成本极低 | 体验补充 |
| 8 | 大话题分页渲染 | 每次渲染最近 100 条，上滑加载更早，避免老手机卡顿 | 性必要 |

**待确认项（已按默认值设计，评审时可改）：**

| 问题 | 默认方案 |
|------|---------|
| 对话是单侧还是双侧（能否区分"我/对方"两种气泡）？ | **单侧**：所有消息都是自己发的、统一右侧气泡（同"文件传输助手"）。数据结构预留 `role` 字段便于将来扩展 |
| 带时间导出的时间取值？ | 消息**创建时间**（编辑不改变它），格式 `YYYY-MM-DD HH:mm:ss` |
| 导出文件格式？ | `.txt`（UTF-8），文件名 `话题名_YYYYMMDD-HHmm.txt` |

## 3. 功能规格

### 3.1 话题列表页

- 顶栏：标题「对话笔记」；**右下角 FAB（＋）** 新建话题，便于单手快速启动。
- **新建无需输入标题**：点击 FAB 直接创建空话题并进入对话；默认显示「新话题」。
  - 发送**第一条消息**时，若用户未手动命名，自动取该消息**首行前 12 个字**作为话题标题；
  - 手动重命名后（`nameSet` 标记），标题不再被自动覆盖；重命名允许留空（回到默认名且不再自动命名）。
- 列表项三行信息：
  - 话题名（超长省略）；
  - 预览：**有草稿时优先显示草稿**（`草稿：` 前缀、置灰），否则显示最后一条消息（单行省略）；
  - 时间：今天 `HH:mm`；昨天显示「昨天」；今年内 `M月D日`；跨年 `YYYY年M月D日`。
- 排序：按最后活跃时间（最新消息或最新草稿的更新时间）倒序。
- 长按列表项（桌面 hover 出「⋯」）→ 弹出菜单：**重命名 / 删除**。
  - 删除确认弹窗：「删除话题“XX”及其 N 条笔记？此操作不可恢复」，确认后连同草稿一起清除。
- 空状态：居中提示「点击右下角的 ＋ 开始记录」。

### 3.2 对话页

- 顶栏：返回（←）、话题名（点击可重命名）、右上「⋯」菜单：**多选 / 导出 / 重命名 / 删除话题**。
- 消息区：
  - **日期分隔条**：居中灰条，「今天」「昨天」`M月D日`、跨年 `YYYY年M月D日`。
  - 每条消息：右侧气泡；气泡旁小字时间 `HH:mm`；编辑过的消息在时间旁加「已编辑」。
  - 消息文本保留换行，`white-space: pre-wrap`。
  - 渲染用 `createElement`/`textContent`，不拼 HTML（防注入）。
  - **分页**：首次只渲染最近 100 条并定位到底部；上滑到顶加载更早 100 条，并用 scrollTop 补偿保持不跳动。
- 输入区：
  - 自动增高 textarea（最多约 5 行后内部滚动），随软键盘保持可见（见 §5.3）。
  - **「展开」按钮**：一键切换全屏多行编辑（textarea 占满整屏，「收起 / 发送」按钮在底部）；收起后内容保留回小输入框。
  - **回车恒为换行**（含输入法 composing 场景），发送仅通过按钮。
  - 发送按钮；trim 后为空禁止发送（按钮置灰）。
  - 发送成功：追加消息、清空该话题草稿、滚动到底、更新列表预览（首条消息触发自动命名，见 §3.1）。
- 空状态：居中提示「记录下第一条笔记吧」。

### 3.3 消息操作（长按菜单）

- 触发：移动端长按 480ms；桌面端 hover 气泡出现「⋯」小按钮，点击打开同一菜单。
- 菜单项：**复制 / 编辑 / 删除 / 多选**。
- 长按与滚动手势冲突处理：按下后若位移超过 10px 或抬起，取消长按计时。
- 气泡设 `user-select: none; -webkit-touch-callout: none;`，避免 iOS 长按弹出系统选择/放大镜，菜单优先（复制走菜单，牺牲气泡内手动划选）。
- **复制**：仅复制该条文本，toast「已复制」。
- **编辑**：弹窗 textarea（预填原文），保存：文本更新、`edited: true`、`createdAt` 不变；trim 为空禁止保存。编辑最后一条时同步列表预览。
- **删除**：确认后删除，toast「已删除」。

### 3.4 多选模式

- 进入：长按菜单「多选」或顶栏「⋯ → 多选」。进入时当前这条消息默认选中。
- 界面切换：
  - 顶栏变为：`已选 n`｜**全选**｜**取消**（退出多选）；
  - 底部操作栏替换输入区：**导出（n）**＋**删除所选**。
- 点击气泡切换选中态（气泡高亮 + 右上角对勾）。
- 「全选」为当前已渲染+未渲染的全部消息（分页不影响全选语义）。

### 3.5 导出

**入口两个：**
1. 顶栏「⋯ → 导出」：非多选状态，范围默认「全部条目」。
2. 多选模式底部「导出」：范围默认「已选条目」。

**导出面板（底部弹层）：**

| 配置 | 选项 |
|------|------|
| 范围 | 全部条目 / 已选条目（仅多选模式下出现「已选」） |
| 时间 | 包含时间（默认）/ 不含时间 |
| 执行 | 「下载 TXT」和「复制到剪贴板」两个并列按钮 |

**格式精确定义**（两种方式输出内容完全一致，仅交付形式不同）：

带时间：

```
2026-08-30 14:23:05
今天买了咖啡

2026-08-30 15:02:11
第二条
多行内容保留
```

不含时间（只含文本）：

```
今天买了咖啡

第二条
多行内容保留
```

规则：
- 时间用消息**创建时间**，本地时区，格式 `YYYY-MM-DD HH:mm:ss`；
- 消息内部换行原样保留；**条目之间用一个空行分隔**；
- 编辑过的消息导出编辑后的最新文本。

**下载**：`Blob`（`text/plain;charset=utf-8`）+ `a[download]`；文件名 `{话题名}_{YYYYMMDD-HHmm}.txt`，话题名中过滤 `\ / : * ? " < > |` 及首尾空格。完成后 toast「已下载 N 条」。

**复制**：优先 `navigator.clipboard.writeText`（https 安全上下文）；失败或非安全上下文降级为隐藏 `textarea` + `document.execCommand('copy')`；两者皆失败 toast「复制失败，请长按手动复制」。完成后 toast「已复制 N 条」。

### 3.6 草稿（未发送内容持久化）

- 每个话题独立草稿，key 为话题 id。
- 保存时机（三重保障）：
  1. 输入事件，防抖 300ms；
  2. `visibilitychange → hidden`；
  3. `pagehide`（覆盖 iOS 上滑杀进程、直接关标签页）。
- 恢复时机：进入话题时回填输入框（光标在末尾），无论刷新还是重开浏览器都在。
- 发送成功 → 清空该话题草稿；切换话题互不干扰。
- 列表预览显示草稿（见 §3.1）。

## 4. 数据模型与存储

存储介质：`localStorage`（纯文本量级足够，同步写、无事务复杂度）。

| Key | 内容 |
|-----|------|
| `chatnote:data.v1` | 全部话题与消息（JSON） |
| `chatnote:drafts.v1` | `{ [topicId]: string }` |

```jsonc
{
  "version": 1,
  "topics": [
    {
      "id": "uuid",              // crypto.randomUUID()，降级 Date.now()+随机串
      "name": "灵感捕捉",
      "createdAt": 1756524000000,
      "updatedAt": 1756524000000, // 最后活跃时间，列表排序用
      "messages": [
        {
          "id": "uuid",
          "text": "今天买了咖啡",
          "createdAt": 1756524000000,
          "updatedAt": 1756524000000,
          "edited": false
        }
      ]
    }
  ]
}
```

**写入策略**：
- 内存为唯一真相源；任何变更（发消息/编辑/删除/新建/重命名/草稿输入）后防抖 300ms 写入；
- `pagehide`/`visibilitychange(hidden)` 时立即同步 flush，防止移动端杀进程丢数据；
- 所有写入 try/catch：失败（隐私模式、配额满）toast「保存失败，数据可能未保留」，并降级为仅内存可用；
- 版本字段 `version` 预留后续迁移。

## 5. 技术方案

### 5.1 形态
- 单文件 `index.html`，原生 HTML/CSS/JS，无框架、无 CDN 依赖、无构建。
- 移动端优先布局，桌面端可用（内容列最大宽约 640px 居中）。

### 5.2 布局与路由
- 整体 `height: 100dvh`，flex 纵向：顶栏 / 消息区(flex:1, overflow auto) / 输入区。
- `viewport-fit=cover` + `env(safe-area-inset-bottom)` 处理底部安全区。
- hash 路由 + `hashchange` 监听；`#/c/` 指向不存在话题时回列表。

### 5.3 软键盘适配（关键）
- 首选 `<meta name="viewport" ... interactive-widget=resizes-content>`（Android Chrome 生效）。
- iOS Safari 用 `visualViewport` 监听：键盘弹起时把视口高度实时赋给应用容器并保持输入框滚动到可见。
- 输入框获焦时，消息区滚到底部。

### 5.4 其他
- 时间显示与导出均用本地时区格式化。
- 深浅色：CSS 变量 + `prefers-color-scheme`。
- 已知限制（记录在案）：多标签页同时打开不保证实时同步，后写覆盖先写。

## 6. 边界与异常清单

| 场景 | 处理 |
|------|------|
| 发送空白（仅空格/换行） | 禁止发送 |
| 编辑清空文本 | 禁止保存 |
| 话题名为空/超 20 字 | 必填校验 / 截断 |
| 长按后手指滑动 | 取消长按（视为滚动） |
| 多选 0 条点导出 | 按钮禁用 |
| 删除话题/消息/所选 | 一律二次确认，明确「不可恢复」 |
| localStorage 写入失败 | toast 告警，功能继续但仅内存 |
| 打开已删除话题的链接 | 回退列表页 |
| 空话题 | 允许存在，预览显示占位文案 |
| 复制在 file:// 下 | execCommand 降级 |
| 消息数很大 | 分页渲染（100/页）+ 全量数据仍存 localStorage（约 5MB 上限，纯文本可用很久） |

## 7. 验收清单

**列表页**
- [ ] FAB 新建：直接创建空话题并进入，无需输入标题；显示「新话题」
- [ ] 首条消息自动命名（首行前 12 字）；手动重命名后不再被自动覆盖；重命名留空回到默认名
- [ ] 重命名 / 删除（确认弹窗含话题名与条数，删除后草稿同步清除）
- [ ] 排序随最新活跃变化；发消息、编辑、草稿都会顶到最上
- [ ] 草稿预览「草稿：」前缀；无消息话题显示占位
- [ ] 时间显示分级正确（HH:mm / 昨天 / M月D日 / 跨年）

**对话页**
- [ ] 发送、连续发送；空白禁止；回车恒为换行（不触发发送）
- [ ] 「展开」切换全屏多行编辑，收起后内容保留；展开状态下可正常发送
- [ ] 日期分隔条正确；气泡时间、「已编辑」标记正确
- [ ] 长按菜单四项功能全部可用；滑动手势不误触
- [ ] 编辑保留原创建时间，最后一条编辑后列表预览联动
- [ ] 上滑分页加载更早消息，滚动位置不跳动
- [ ] 软键盘弹起输入框始终可见（iOS Safari + Android Chrome 实测）

**多选与导出**
- [ ] 进入/退出多选、全选、计数正确
- [ ] 删除所选需确认且正确移除
- [ ] 范围（全部/已选）× 时间（含/不含）四种组合导出内容与 §3.5 格式一致
- [ ] 下载：文件名正确、中文不乱码（iOS/Android/桌面）
- [ ] 复制：https 与 file:// 两种环境均成功，失败有提示
- [ ] 导出面板两种入口默认范围正确

**草稿与存储**
- [ ] 输入内容后直接关闭浏览器/杀进程，重开内容还在（重点用例）
- [ ] 切换话题草稿互不串
- [ ] 发送后草稿清空、预览更新
- [ ] 刷新页面全部数据完整
- [ ] 隐私模式下有「保存失败」告警且不崩

## 8. 明确不做（V1 范围外）

搜索、话题置顶/图标、导入备份（JSON 全量导出/导入）、多端同步、图片语音附件、双侧角色气泡、PWA 离线安装、i18n。可在后续版本迭代（数据结构已预留 `version` 与 `role`）。
